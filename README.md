# homebrew-tap

Homebrew tap for `mochi-sticky`.

## Install

```bash
brew tap mochizerodev/tap
brew install mochi-sticky
mochi-sticky --version
```

## Update (per `mochi-sticky` release)

Update `Formula/mochi-sticky.rb` with the new `version`, `url`, and `sha256` values from the GitHub Release assets.

If you enable the included GitHub Actions workflow, you can also run the “Update mochi-sticky formula” workflow to open an automated PR.
